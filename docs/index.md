# __Welcome to ScurryPy__
---
ScurryPy is a fully extensible foundation for Discord bots and frameworks. 

## Features
---
ScurryPy is designed to be small, predictable, and transparent.

* Lightweight core
* Strictly typed
* Rate limit handling
* Automatic session & gateway management
* Automatic sharding
* Predictable behavior
